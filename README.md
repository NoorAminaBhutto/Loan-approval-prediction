# Loan Approval Prediction

This is my BigBrainz Internship Project (Phase 1 to 8).

### Project Goal
To predict if a loan will be Approved or Rejected based on applicant details.

### Files in this Repository
1.  `app.py` - Main Streamlit web application with Logistic Regression model
2.  `requirements.txt` - Required libraries (pandas, scikit-learn, streamlit)
3.  `README.md` - Project documentation

### Tech Stack
- Python, Pandas, Scikit-Learn
- Streamlit for Deployment
- Logistic Regression Model

### How to Run
`streamlit run app.py`
